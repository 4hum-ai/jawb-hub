# Security and abuse reports

## Report a listed extension

- **Something sensitive** (a vulnerability, malware, data exfiltration):
  open a **private vulnerability report** on this repository (Security tab,
  "Report a vulnerability"). Only maintainers see it.
- **Anything else** (a broken source, a misleading description, a
  never-list item, a name dispute): open a "Report an extension" issue.

Include the extension id, the version, and what you saw.

## What happens next

1. A maintainer acknowledges the report.
2. If the problem is confirmed, the target is to remove the listing within
   24 hours, and, once jawb's signed index carries third-party listings,
   to revoke the version so installed copies switch off (TERMS.md,
   section 3).
3. The publisher is told when that is safe to do. A fixed version can be
   listed as a new version.

Reports about jawb itself (the browser, `jawbd`, the CLI) go to the jawb
project, not here.
