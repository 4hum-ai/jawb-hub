# site-screens

A jawb extension (template). The package is in [`extension/`](extension):
`extension.toml`, `schemas/` and its README. The rest of this repository is
yours: `.github/workflows/release.yml` packs `extension/` into a release
asset on each `v<version>` tag.

Try it: `jawb extension load --dev ./extension`. The tutorial is in
[jawb-hub/docs](https://github.com/4hum-ai/jawb-hub/blob/main/docs/tutorial.md).
